# Incident Status Update Template

Use this during an incident. Prefer facts, timestamps, and next checks over
long explanations.

## Update

- Time:
- Status: investigating | identified | mitigating | monitoring | resolved
- Impact:
- Evidence:
- Current hypothesis:
- Action now:
- Next update by:

## Rules

- Say what users are experiencing, not only what component is failing.
- Separate confirmed evidence from hypotheses.
- Include one next action and one next update time.
- Do not include secrets, full connection strings, request bodies, or raw
  customer data.
- Do not claim resolution until health, durable status, and recent logs support
  it.
